# Agent Rules For The Public Reproduction Repo

This repository is the curated, public-facing reproduction system for the
DINO/I-JEPA SAE Feature Economy paper. Treat it as an executable research
artifact, not as a private scratchpad.

## Core Contract

The default path is full paper-style rerun from user-provided datasets,
backbone checkpoints, SAE checkpoints, and GPU resources. Lightweight fixture
and closed-form paths exist for smoke tests, CI, and debugging only.

When adding or changing functionality, preserve this separation:

- `configs/` defines model, task, SAE, probe, sweep, and advanced-analysis
  matrices.
- `src/feature_economy/` implements reusable command backends and artifact
  schemas.
- `scripts/` contains shell/Python orchestration and release utilities.
- `docs/` explains how to reproduce, audit, extend, and validate the chain.
- `tests/` keeps small deterministic checks that do not require private data.

## No Private Assumptions

Do not add private absolute paths, cluster-specific launchers, unpublished
artifact locations, or local checkpoint names to public commands or configs.
Use environment variables such as `${DATA_ROOT}`, `${SAE_ROOT}`, and
`${ARTIFACT_ROOT}`.

Do not commit datasets, model checkpoints, SAE checkpoints, large feature/code
arrays, probe caches, logs, or generated release bundles.

## Experiment Additions

Prefer config-driven additions over one-off scripts. A new model, layer, task,
SAE setting, ranking method, or analysis module should normally add:

- one or more YAML configs;
- a run-plan row generated by `feature-economy plan-runs`;
- an artifact schema or extension if new outputs are introduced;
- a smoke/unit test using tiny arrays;
- documentation in `docs/experiment_matrix.md` or the relevant runbook.

If a third near-duplicate runner appears, stop and parameterize the common path
or write a family note explaining why the branches must remain separate.

## Validation Before Commit

Run the lightest meaningful validation for the touched area:

```bash
PYTHONPATH=src python -m feature_economy.cli.main check-configs --config-root configs
PYTHONPATH=src python -m feature_economy.cli.main plan-runs --config-root configs --output-json /tmp/feature_economy_plan.json
PYTHONPATH=src python -m unittest discover -s tests
PYTHONPATH=src python scripts/check_public_release.py --root .
git diff --check
```

If a change only edits docs, still run `scripts/check_public_release.py` when
the docs contain links, fenced commands, or release-path references.

## Paper Evidence Boundary

The public repo should reproduce conclusions and close numerical behavior, not
bit-identical private caches. If a public command intentionally differs from the
private implementation, document the difference and whether it is:

- a smoke-only approximation;
- a saved-array audit path;
- a paper-style default;
- a future extension placeholder.

NYUv2 perturbation-response analysis is intentionally outside the current public
default chain. Do not add it casually as a one-off script.
